= connectrpc-spring

Reference documentation for `connectrpc-spring`, which serves the https://connectrpc.com[Connect protocol] from existing gRPC service definitions on plain Spring WebFlux -- no code changes to the service itself.

Real content for this page -- getting started, configuration reference, the "why not gRPC-Web" explainer -- is still to come (task-connectrpc-spring-boot-starter Phase 6.3/6.4). In the meantime, see the https://github.com/neilpmas/gs-connect-rpc[`gs-connect-rpc`] getting-started guide.
